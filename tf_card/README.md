# TF 卡准备说明（图片播放用）

本目录里的 4 个 BMP 已经按播放器的要求转换好，直接拷进 TF 卡根目录即可。

## 1. 目录内容

| 文件 | 尺寸 | 大小 | 来源原图 |
| --- | --- | --- | --- |
| `IMG1.BMP` | 640×360 | 691 254 B | `src/pic/dji_mimo_20260825_085410_0042_...photo.jpeg`（3840×2160 横） |
| `IMG2.BMP` | 640×360 | 691 254 B | `src/pic/dji_mimo_20260825_181014_0123_...photo.jpeg`（横） |
| `IMG3.BMP` | 360×480 | 518 454 B | `src/pic/mmexport1793741089808.jpg`（3456×4608 竖） |
| `IMG4.BMP` | 320×480 | 460 854 B | `src/pic/mmexport1793741092025.jpg`（3072×4609 竖） |

竖图保留完整画面，播放时左右自动补黑边（letterbox），不会拉伸变形。

## 2. 播放器对图片的硬性要求

- 文件系统 **FAT32**（exFAT / NTFS 不认）
- 格式 **24 位非压缩 BMP**（索引色、32 位、RLE 压缩都不认）
- 宽度必须是 **4 的倍数**（BMP 每行按 4 字节对齐）
- 单张建议 ≤ 2048×1200，文件头必须是标准 `BM` + 54 字节
- 最多读 **4 张**，且只扫描卡的前 16 MB（图片请放在根目录）
- 文件名用 8.3 短名（如 `IMG1.BMP`），避免中文名与长文件名

## 3. 制作步骤

1. 用容量 ≤32 GB 的 TF 卡，格式化为 **FAT32**（Windows 自带格式化对 >32 GB 的卡没有 FAT32 选项，可用 `guiformat`）。
2. 把 `IMG1.BMP` ~ `IMG4.BMP` 拷到**根目录**。
3. 安全弹出后插到板子上，按一下 K1（或者直接重新上电）。
4. 上电后需要几秒扫卡与预载，随后自动开始轮播；数码管末位显示 `F` 表示状态正常。

## 4. 换图 / 加图

把新照片放到 `src/pic/`，然后在仓库根目录执行：

```bat
python 40_player_release\tools\jpeg_to_bmp.py
```

脚本会自动等比缩放到 640×480 以内、宽度取 4 的倍数、转成 24 位 BMP，并按顺序输出 `IMG1.BMP`…（输出目录见脚本头部 `OUT_DIR`）。若使用本机 Python 没有装 Pillow，请用捆绑环境：

```
C:\Users\cht\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe
```

## 5. 常见问题

| 现象 | 排查 |
| --- | --- |
| 一直停在第一张 / 不进轮播 | 卡不是 FAT32，或图片不在根目录 |
| 画面全黑但字幕正常 | 图片位深不是 24 位，或宽度不是 4 的倍数 |
| 只识别到 2~3 张 | 图片位置超过卡前 16 MB，或文件名过长 |
| 插卡无反应 | 卡座接触不良；换卡后按 K1 重扫 |
| 上电要等几秒 | 正常现象：要先扫目录再预载 4 张图 |
